# GamerHub - React Native & Web Mobile Games Catalog 🎮

A next-generation mobile games catalog, discovery platform, and instant playable mini-games application built with React, React Native Web, and Tailwind CSS.

![GamerHub Mobile Catalog](https://images.unsplash.com/photo-1542751371-adc38448a05e?auto=format&fit=crop&w=1200&q=80)

## ✨ Features

- 📱 **Mobile & Web Responsive UI**: Toggle between full desktop view and realistic iPhone device frame mode.
- 🕹️ **Instant Playable Canvas Mini-Games**: Play games directly in your browser with zero installation (Cyber Runner 2099, Neon Breakout).
- 🔥 **Trending Leaderboards**: Ranked top 10 mobile games with user score metrics and live download statistics.
- 🎯 **Category & Genre Filters**: Action, Retro Arcade, Sci-Fi RPG, Nitro Racing, Puzzles & Strategy.
- 🔍 **Real-Time Search**: Instant filtering across titles, developers, and genres.
- ❤️ **Saved Favorites**: Bookmarking system backed by local storage.
- 👤 **Gamer Profile & Achievements**: XP leveling bar, unlocked badges, and game stats.
- ➕ **Developer Submission Modal**: Submit custom mobile titles to the catalog.

## 🚀 Quick Start (Web & Dev Server)

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## 📦 Build for Production

```bash
npm run build
```

The production output will be generated in the `dist` folder, ready for deployment to Vercel, Netlify, or GitHub Pages.

## 📱 React Native Expo Compatibility

This repository includes `app.json` configuration for React Native Expo workflows.
